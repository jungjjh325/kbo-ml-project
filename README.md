# KBO 선수 성적 예측 (머신러닝 팀 프로젝트)

KBO 선수의 2020\~2025 시즌 기록으로 2026 시즌을 예측하고, 실제 2026 기록(2026-11-04 기준)과 비교한 프로젝트입니다.
계산은 전부 Python(pandas, numpy)으로 하고, 결과는 HTML 한 장(`web/index.html`)으로 봅니다.

> 이 저장소에는 코드만 있습니다. 원본 데이터(`data/`)와 결과물(`output/`, `web/data.js`)은 올리지 않았습니다.

## 가설과 방법

| 가설 | 파일 | 내용 |
|---|---|---|
| 1. 직선 예측 | `python/predict.py` | 선수마다 2020\~2025 값 6개에 직선(`numpy.polyfit` 1차)을 맞춰 2026을 예측. 직전 시즌, 본인 평균, 전체 평균과 MSE 비교 |
| 2. 연령대 분석 | `python/age_analysis.py` | 연령대(3년 단위)별 변화 통계, 나이를 넣기 전후 회귀·분류 성능을 2016\~2026 시즌별로 비교, 회귀 트리로 나이 분기점 찾기 |
| 3. 상승/비상승 분류 | `python/classify.py` | "다음 시즌 지표가 직전보다 오르는가"를 로지스틱 회귀로 분류. IRLS(뉴턴-랩슨)를 numpy로 직접 구현, 다수 클래스 기준모델과 Accuracy 비교 |

- 대상 선수(가설 1, 3): 2020\~2025 여섯 시즌 모두 매년 타자 50 또는 100타석, 투수 20이닝 이상
- 지표: 타자 AVG, SLG, HR/PA, H, HR / 투수 K/9, SO, BB, IP
- 2026 기록은 평가에만 쓰고 학습에는 쓰지 않음

## 주요 결과

- **가설 1**: 직선 예측은 "전체 선수 평균"보다는 대부분 나았지만, "직전 시즌 그대로"나 "본인 평균"과는 지표마다 엇갈렸습니다 (HR은 직선이 더 나쁨).
- **가설 2**: 나이를 넣어도 예측 오차와 정확도는 거의 달라지지 않았습니다. H·HR은 34세 이후 눈에 띄게 줄지만 대부분 출전 감소 때문입니다.
- **가설 3**: 직전 시즌 값 + 변화량을 쓴 모델이 많은 지표에서 다수 클래스 기준보다 정확했지만, 평가 인원이 22\~54명이고 2026년 한 해라 차이는 우연일 수 있습니다.

## 화면 (web/index.html)

- **선수 조회**: 이름 검색, 지표별 2026 예측·본인 평균·전체 평균, 추이 그래프(SVG), 2026 상승 확률, "2026 실제값 공개" 버튼
- **지표별 비교표**: 직선 예측의 MSE ÷ 기준 예측의 MSE
- **상승/비상승 분류**: 기준모델 / 모델 1 / 모델 2 Accuracy
- **연령대 분석**: 연령대별 막대 그래프, 나이 넣기 전후 비교, 회귀 트리 분기점

화면은 `index.html` 파일 하나이며, 계산은 하지 않고 Python이 만든 `data.js` 값만 보여줍니다. 디자인(색, 배치)과 검색·탭·그래프 동작도 이 파일 안에 들어 있고, 외부 라이브러리는 쓰지 않았습니다.

## 실행

```
data/   kbo_hitters_season_1982_2026.csv, kbo_pitchers_season_1982_2026.csv, kbo_people.csv  (직접 준비)
python/ 코드
web/    index.html
```

```bash
cd python
python run_all.py      # output/ CSV 와 web/data.js 생성
```
그다음 `web/index.html` 을 브라우저로 엽니다. 필요 패키지: pandas, numpy.
